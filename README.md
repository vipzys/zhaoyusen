# 赵渝森 — 一卡主剪 · 个人作品集

暗色、电影感、克制的单页作品集。使用 **React 18 + Vite 5** 构建，无 UI 框架依赖；所有图形由 CSS / SVG 绘制，动效使用 **GSAP + ScrollTrigger + Lenis**。

> 已根据赵渝森的最新简历更新姓名 **赵渝森 / 一卡主剪**、邮箱 **exle@qq.com**、微信、教育背景、工作经历、代表项目与真实播放数据。人物肖像与精选项目封面均由赵渝森本人提供。

## 运行

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:5173`。

生产构建：

```bash
pnpm build
pnpm preview
```

站点是纯静态页面，作品视频不在站内。作品集入口会展开一个轻量面板，并提供百度网盘分享链接与提取码。

完整 Cloudflare Pages 部署步骤见 [DEPLOY.md](./DEPLOY.md)。

## 部署速览

- `dist` 约 **7–8MB**
- 作品视频不进入站点，通过百度网盘外部链接查看
- 推荐 **Cloudflare Pages**：构建命令 `pnpm build`，输出目录 `dist`
- 已提供 [public/_redirects](public/_redirects) 作为 SPA 回退
- 上线时只需绑定域名，Cloudflare 自动配置 HTTPS

## 页面结构

1. **Hero** — 全屏视频背景、城市夜色底图、主标题、导航与联系按钮。视频以 `screen` 混合模式叠加在底图上，形成烟雾流动感。
2. **个人经历** — 使用真实肖像、个人介绍、工作经历、教育背景与 4 组数据。
3. **精选项目** — 三张真实项目大卡片，按 7 / 4 / 12 栏非对称排布；点击项目画面展开作品集入口。
4. **全部作品 / 片库** — 作品视频不在站内存储；展开后显示百度网盘分享按钮与提取码 `a21p`，一键跳转网盘页面。
5. **个人优势** — 5 张能力卡片，附带留存曲线、节奏波形、剪辑时间线、声音表盘与 AI 工作流等原生图形。
6. **联系收尾** — 整屏收束页，保留超大标题、邮箱、微信与复制邮箱按钮，作为页面最底部内容。

视觉版心由 CSS 变量 `--max: 1700px` 控制，PC 端优先，同时提供平板和移动端适配。

## 动效设计

- **完整开场**：模拟剪辑软件操作界面，时间线从空白逐步填满素材，进度到 100% 后界面收束为一个播放按钮，随后进入 Hero 标题遮罩进场。
- **Lenis 惯性滚动**：滚轮和锚点跳转带持续缓动，章节会自然滑入目标位置。
- **模块标题**：每个模块先进入大号英文斜体标题，再以遮罩、位移和轻微压缩揭开中文主标题，最后进入说明文字。
- **滚动中的持续动效**：英文/中文标题块随模块滚动缓慢漂移，章节横线随进入进度展开，人物肖像与项目图片保持反向视差。
- **片库独立展开**：点击作品集入口先进入全屏过渡页（幕布上移、内容切换），再揭示百度网盘链接面板。
- **卡片节奏**：项目、能力卡片按 ScrollTrigger 依次 stagger 进场，图片使用 `clip-path` 向上揭幕。
- **滚动视差**：人物肖像、项目图片在卡片内反向位移，滚动速度越快，画面层次越明显。
- **滚动光晕**：页面背景中的暖色光晕随滚动进度缓慢下移，增强上下浏览的空间感。
- **逐字 / 逐行动画**：Hero 标题按字符升起；章节标题使用遮罩式 line reveal。
- **鼠标空间感**：Hero 标题随指针做低幅度视差；主按钮、联系邮箱带有磁吸跟随。
- **卡片互动**：项目图片有聚光灯跟随、标题上浮、图片放大；能力卡片有聚光、边框描边和图形抬升。
- **收尾页氛围**：橙色光晕缓慢呼吸、背景剧照漂移、超大「赵渝森」字标横向游移，联系区作为页面最终画面。
- **菜单与内容**：移动端菜单逐项上浮；职业经历、能力列表与工具信息分批入场。
- **动效策略**：站点默认保留完整的开场、滚动与片库过渡；动效由站点自身控制，不因系统「减少动态效果」偏好自动关闭。

## 实现细节

- 视频 `muted / loop / playsInline` 自动播放，并与页面动效同步。
- 原生系统光标、加载序列、滚动进度、章节高亮、数字递增、图片视差与进入视口动画。
- `MotionDirector` 在首屏结束后统一注册 ScrollTrigger，所有进场动画只播放一次，避免持续滚动 scrub 带来的性能损耗。
- 导航锚点平滑滚动，并自动避开固定导航；所有动画使用 transform / clip-path，避免布局抖动。
- 邮箱支持一键复制；微信与邮箱显示在页面底部主联系区。
- 所有字体、图片和 Hero 视频均已本地化；作品视频通过百度网盘外部链接提供。
